# Домашнее задание к работе 9
## Задание номер 8.
Написать программу, выводящую на экран заданную геометрическую фигуру, нарисованную с помощью заданного с клавиатуры символа. Предусмотреть возможность изменения размеров фигуры путем задания ее размеров в количестве символов пользователем.
## 1. Алгоритм и блок-схема
1. Начало
2. объявить переменные ch,stl,str,x,y,n
3. Ввод данных ch, n
4. Цикл (str=0; str<n; str++)
5. Нахождение координаты y
6. Внутренний цикл (stl=0; stl<n; stl++)
7. Нахождение координаты x
8. Проверка условия, входят ли координаты в плозадь фигуры, если истина - рисуется символ, нет - пробел
9. В внешнем цикле переход на следующую строку
10. Конец
